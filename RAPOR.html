Öğrenci: İbrahim Çam  |  GitHub: github.com/cibrahim58  |  Tarih: 2025

1. Proje Özeti

Bu proje; HTML5, CSS3, JavaScript, PHP ve MySQL teknolojileri kullanılarak geliştirilmiş, tam yığın (full-stack) bir kişisel portfolyo web uygulamasıdır. Statik bir sayfa olmaktan çok, veritabanıyla bütünleşik dinamik bir web uygulamasıdır.

4. Öne Çıkan Teknik Detaylar

Güvenlik

  • Tüm kullanıcı girdileri htmlspecialchars() ve trim() ile temizlenir
  • Veritabanı işlemleri PDO Prepared Statements ile yapılır (SQL Injection koruması)
  • Admin şifresi password_hash() / password_verify() ile saklanır
  • Session timeout (30 dakika) ve session_regenerate_id() uygulandı

Performans & UX

  • IntersectionObserver ile scroll-triggered animasyonlar (layout reflow yok)
  • Özel CSS cursor, blob animasyonları, skill bar geçişleri
  • Counter animasyonu sayısal değerleri kademeli artırarak gösterir
  • Tema tercihi hem Cookie hem localStorage'de saklanır

6. Kullanılan Teknolojiler

  • Frontend: HTML5, CSS3 (Custom Properties, Flexbox, Grid, Animations), Vanilla JavaScript (ES6+, Fetch API, IntersectionObserver)
  • Backend: PHP 8+, PDO
  • Veritabanı: MySQL 8 / MariaDB
  • Fontlar: Syne (display), DM Sans (body) — Google Fonts

7. Kurulum

  1. Dosyaları hosting'e veya XAMPP/WAMP'a yükleyin
  2. portfolio_db.sql dosyasını phpMyAdmin'den import edin
  3. php/db.php içindeki DB_USER ve DB_PASS değerlerini güncelleyin
  4. Admin paneline /admin/login.php adresinden erişin (admin / password)
